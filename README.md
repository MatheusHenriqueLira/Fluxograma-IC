# Fluxograma IC

## Como rodar

1. Entre na pasta do projeto:
   ```bash
   cd fluxograma-ic
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o projeto em modo de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Abra o endereço exibido no terminal, normalmente:
   ```text
   http://localhost:5173
   ```
